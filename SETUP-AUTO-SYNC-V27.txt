SALES DASHBOARD — METABASE AUTO UPDATE SALES v27
===================================================

FINAL RULE
----------
Auto Update Sales runs 4 times/day:
- 00:00 WIB
- 06:00 WIB
- 12:00 WIB
- 18:00 WIB

Date rule:
- start_date = tanggal 1 bulan berjalan
- end_date   = tanggal hari ini
- timezone   = Asia/Jakarta

Example:
13 Sep 2026:
  start_date = 2026-09-01
  end_date   = 2026-09-13
  target     = folder 2026-09

Every run REPLACES the current month's data. It does not append duplicates.

F. SCHEDULE
-----------
The workflow uses UTC because it is the most compatible GitHub Actions schedule.

Cron:
0 5,11,17,23 * * *

Conversion:
05:00 UTC = 12:00 WIB
11:00 UTC = 18:00 WIB
17:00 UTC = 00:00 WIB (Jakarta next date)
23:00 UTC = 06:00 WIB (Jakarta next date)

The server itself always calculates the report date using Asia/Jakarta.
So the 00:00 run uses the correct Jakarta date.


G. SAFETY / MEMORY
------------------
v27 keeps the previous protections:
- monthly gzip storage
- no full-history RAM cache
- only one heavy dashboard query at a time by default
- short result cache for multiple users
- dashboard sections initially load sequentially
- manual upload and Auto Sync cannot write sales data simultaneously
- duplicate scheduler runs are blocked
