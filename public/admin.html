Monthly Raw Sales Storage

Data sales disimpan per bulan di persistent storage Railway: /app/data/monthly/YYYY/MM.json.gz. Setiap upload hanya untuk 1 bulan. Bulan yang sama dapat diupload ulang kapan saja, termasuk 1, 2, atau beberapa bulan sebelumnya. Upload terbaru akan replace seluruh data pada folder bulan tersebut, sehingga tidak duplicate.

Halodoc Merchant Rejection

Input manual per minggu (Senin–Minggu). Isi Order dan Reject agar % dihitung otomatis, atau isi langsung Reject % bila hanya punya persentase. Store yang dikosongkan dianggap belum ada data (berbeda dengan 0%). Bisa paste satu kolom dari Excel ke baris pertama.

Import dari Excel

Upload file rekap Halodoc Rejection Anda (format: kolom pertama nama store, satu baris header berisi W1, W2, ..., baris Grand Total di bawah). Nilai boleh berupa persen (3%) atau desimal (0.03). Sel kosong = belum ada data. Minggu yang ada di file akan menggantikan data minggu yang sama di dashboard.
