Upload Raw Excel

Upload file Excel dari Metabase/manual. File harus memiliki sheet RAW atau sheet pertama dengan kolom transaksi yang sesuai. Data customer pribadi tidak disimpan ke cache dashboard; hanya field yang dibutuhkan untuk reporting.


Channel Master

Tambah/rename display channel, mapping Raw Value, urutkan, aktif/nonaktifkan channel. Raw Value dicocokkan dengan kolom TELEMED dari raw. Flag Telemed hanya memengaruhi row summary TOTAL TELEMED.

Store / PT Master

Raw Name harus sama dengan store_location pada file raw. Satu display store boleh memiliki lebih dari satu Raw Name. PT yang tersedia: EFM, EFIT, ESB.
